# ꒰소매꒱ 길드 홈페이지 · Photo & Music Edition

## 사용법
ZIP 압축을 푼 후 `index.html`을 브라우저에서 엽니다. `assets/` 폴더는 반드시 함께 업로드하세요.

## 기능
- 갤러리: 직접 전달받은 길드 스크린샷 5장, 사진 확대/화살표/키보드 탐색
- 입장 화면: 음악과 함께 / 조용히 입장
- 음악: OH MY GIRL – Dun Dun Dance (사용자 업로드 음원), 재생·일시정지, 볼륨 기억, 무한 반복
- 공식 디스코드: https://discord.gg/kPFvPhjZR8
- 길드퀘 일정 .ics 내보내기 / 규칙 검색 / 주제 필터 / 테마 변경 / ASA 이스터에그

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 압축 해제된 `index.html`, `assets/`, `README.md`를 저장소 루트에 올립니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. GitHub Pages 주소에서 확인합니다.

## 유의사항
- 배경음악은 버튼을 클릭한 경우에만 재생됩니다(브라우저 정책).
- 사용자가 제공한 상업 음원은 공개 배포/재전송 권한이 별도로 필요합니다. GitHub Pages 공개 전에 권리자의 허락 또는 적절한 라이선스를 확인하세요.
- 2026-08-06 안내를 우선하여 비공정 규칙은 삭제 처리했습니다. 과거에 촬영된 선박 사진은 길드 추억 사진으로만 사용됩니다.
