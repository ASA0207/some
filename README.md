# ꒰소매꒱ 길드 홍보 홈페이지

## 사용하기
1. 압축 해제 후 `index.html`을 브라우저로 열어 확인하세요.
2. GitHub 저장소 루트에 `index.html` 및 `assets/` 폴더를 업로드하세요.
3. Settings → Pages → Deploy from a branch → main / root 를 선택하세요.

## 기능
- 첫 방문 입장 화면, 별빛/입장 파티클, 라이트/다크 모드, 반응형 디자인
- 길드 소개, 게임 사진 갤러리, 일정 .ics 다운로드, 검색/필터 가능한 규칙, 등급 안내
- 키보드로 `asa` 입력 시 이스터에그

## 수정 포인트
- `index.html`의 `가입 문의 안내` 버튼 안내 문구에 실제 연락처를 추가할 수 있습니다. 현재 링크를 임의로 만들지 않았습니다.
- 갤러리의 갤러리 이미지 URL 또는 `assets/gallery-*.svg` 파일을 소매 길드 실제 스크린샷으로 바꾸세요.
- 비공정 삭제 및 길드 팜 낚시 복원 공지(2026-08-06)를 기준으로 비공정 관련 규칙은 넣지 않았습니다.
- 외부 게임 스크린샷을 예시로 불러오며 인터넷이 없을 때는 동봉된 일러스트가 표시됩니다. 공개 사용 전에 원저작권자 이용 허락/라이선스를 확인하고, 가능하면 직접 촬영한 길드 스크린샷으로 대체하세요.
- 이 사이트에는 외부 광고/추적 스크립트가 없습니다. Google Fonts 로드에는 인터넷 연결이 필요합니다.
